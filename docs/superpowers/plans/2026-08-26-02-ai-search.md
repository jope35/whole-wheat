# Plan 2 — AI Search

Spec: `docs/superpowers/specs/2026-08-25-whole-wheat-design.md`  
Depends on: Plan 1 `PageRow` table contract only  
Produces: `Hit` contract, retriever, index created from the notebook

Do not import LangGraph. Do not call Foundation Models.

## Goal

A reader runs `notebooks/02_ai_search.py`, creates a Delta Sync index on the page table, and sees `ann`, `FULL_TEXT`, and `hybrid` return the same `Hit` shape.

## Files

- `databricks.yml` — add `ai_search_endpoint` resource (endpoint only)
- `src/whole_wheat/contracts.py` — `Hit` (same fields as `PageRow`)
- `src/whole_wheat/retriever.py` — `ann`, `keyword`, `hybrid`; optional `year`
- `notebooks/02_ai_search.py`
- `tests/test_hit_contract.py`

## Tasks

1. Add `Hit`. Same keys as `PageRow`. Round-trip JSON.
2. Retriever wraps `AISearchClient`. Map SDK rows to `Hit`. Unknown extra columns are dropped. Missing required keys raise a short error.
3. `year` is an equality filter. Do not add other filters.
4. Notebook: create Delta Sync index, triggered, embeddings `databricks-qwen3-embedding-0-6b` on `text`, wait until ready, run three queries, `display` hits.
5. If the page table is missing, print “run ingest” and stop. Do not ingest here.

## Contract tests (CI)

- A fake SDK row with the page columns maps to `Hit`.
- A fake row missing `chunk_id` is rejected.
- The retriever function signatures accept `query`, `k`, optional `year`.

No live index in CI. Fake the SDK response dict.

## Manual live check

1. Confirm Plan 1 table exists.
2. Deploy so the AI Search endpoint exists.
3. Run the AI Search notebook.
4. Confirm three query types each return a list of hits with `chunk_id`, `source_file`, `page_id`, `year`, `text`.
5. Run one query with `year` set to a fixture year. Confirm every hit has that year, or the list is empty if the fixture year has no match.

Pass: three query types return valid `Hit` JSON. Fail: index create error, empty columns, ingest code inside this notebook.

## Done when

The notebook shows three retrieval methods on your index. CI contract tests pass. Plan 3 can call `retriever` without knowing AI Search.
