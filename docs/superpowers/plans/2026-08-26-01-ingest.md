# Plan 1 — Ingest

Spec: `docs/superpowers/specs/2026-08-25-whole-wheat-design.md`  
Depends on: nothing  
Produces: page-row contract, Delta table, Volume, ingest notebook

Later plans must not parse OfficeQA JSON. They only read page rows.

## Goal

A reader runs `notebooks/01_ingest.py` and gets a Delta table of page rows. First run uses the in-repo fixture. A later cell can pull the frozen Hugging Face subset.

## Files

- `databricks.yml` — bundle variables and ingest notebook task. No AI Search index resource.
- `src/whole_wheat/contracts.py` — `PageRow`
- `src/whole_wheat/ingest.py` — fixture and JSON-file → `PageRow` list → Spark write
- `data/fixture.json` — 2–3 fake pages (valid parsed-JSON *shape*, not a real Treasury file)
- `data/subset.json` — `[]` until you pick basenames during the live HF cell
- `notebooks/01_ingest.py`
- `tests/test_page_row_contract.py`

## Tasks

1. Add `PageRow`: `chunk_id`, `source_file`, `page_id`, `year`, `text`. Round-trip JSON. Reject missing keys.
2. Flatten one parsed-JSON document: keep `text` and `table` elements. One row per page. Drop headers, footers, figures. Truncate `text` at 32,764 bytes.
3. Write the fixture. Parse it with the same function as real files.
4. Notebook cells: widgets for catalog/schema/volume from bundle vars → write fixture files to the Volume → build the Delta table → enable CDF → `display` a few rows.
5. Optional last cells: `HF_TOKEN` → download basenames in `subset.json` → rebuild the table. If the token is missing, stop after the fixture path. Do not fail the notebook.
6. Bundle target variables only. No hard-coded workspace names.

## Contract tests (CI)

- Fixture JSON → list of `PageRow`. Every required key present.
- A page with only a `page_header` produces no row.
- `text` longer than 32,764 bytes is truncated.

No Spark. No workspace.

## Manual live check

1. Fill `catalog`, `schema`, `volume` in the bundle target.
2. Deploy the bundle.
3. Run the ingest notebook.
4. Open the Delta table. Confirm columns match `PageRow`. Confirm at least one fixture row.
5. Optional: set `HF_TOKEN`, fill `subset.json`, rerun the HF cells. Confirm new `source_file` values.

Pass: table matches the contract. Fail: missing columns, empty table, notebook error before the fixture write.

## Done when

The ingest notebook succeeds on the fixture path in your workspace. CI contract tests pass. Plan 2 can treat the table as a black box.
