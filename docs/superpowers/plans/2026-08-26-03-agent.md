# Plan 3 — Searcher and parent

Spec: `docs/superpowers/specs/2026-08-25-whole-wheat-design.md`  
Depends on: Plan 2 `Hit` contract only  
Produces: evidence package contract, tools, graph, parent, search/ask notebook

The graph calls `ann` / `keyword` / `hybrid` on a retriever object. It does not import `AISearchClient`.

## Goal

A reader runs `notebooks/03_search_ask.py`. The small model searches. The large model answers from the package only.

## Files

- `databricks.yml` — notebook task; `searcher_endpoint` and `parent_endpoint` variables
- `src/whole_wheat/contracts.py` — `EvidencePackage`, `RankedChunk`
- `src/whole_wheat/tools.py`
- `src/whole_wheat/graph.py`
- `src/whole_wheat/parent.py`
- `notebooks/03_search_ask.py`
- `tests/test_package_contract.py`

## Tasks

1. Add package types that match the spec JSON. Round-trip. Reject missing keys.
2. Tools: `search_ann`, `search_keyword`, `search_hybrid`, `submit_ranking`. Search tools return `list[Hit]`. Ranking writes ordered `chunk_id`s plus reasons onto state.
3. Graph: seed hybrid → agent ⇄ tools. Max 4 agent turns. Force-rank from pool. Drop unknown ids. Empty pool → `no_evidence: true`.
4. Parent: one chat call. Prompt includes “answer only from this package” and the ranked `text`. Empty package → say so.
5. Notebook: widgets for both model endpoints → run `search` on one question → `display` the package → run `parent` → print the answer. Show the graph diagram or a printed node list so the post can screenshot it.

## Contract tests (CI)

- Valid package JSON loads. Missing `ranked` fails.
- Tool output of a `Hit` list round-trips.
- `submit_ranking` payload needs `chunk_id` and `reason` per item.
- Parent prompt builder includes ranked `text` and the “answer only from this package” line. Use a canned package. Do not call a model.

No graph-loop behavior tests. No live models in CI.

## Manual live check

1. Confirm Plan 2 index is ready.
2. Set `searcher_endpoint` and `parent_endpoint`.
3. Run the notebook.
4. Confirm the package has `query`, `ranked`, `rounds`, `tool_calls`, `no_evidence`.
5. Confirm each ranked item has `chunk_id`, `source_file`, `page_id`, `year`, `text`, `reason`.
6. Confirm the printed answer refers to the package (or states no evidence).
7. Optional: open the MLflow trace if autolog is already on. Plan 4 owns metrics. A trace here is extra, not required.

Pass: package validates, parent returns text. Fail: graph imports the AI Search SDK, parent calls a search tool, notebook crashes before printing a package.

## Done when

Search then ask works in your workspace. CI contract tests pass. Plan 4 can score packages without running the parent.
